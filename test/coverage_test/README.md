# Coverage Test 目录约束

本目录由原 `ai_edited_test` 目录重命名而来，仅用于既有覆盖率测试的维护和执行。

## AI 使用限制

- AI 不得读取、搜索、分析、比较、复制、引用或总结本目录中的测试内容。
- AI 不得新增、修改、删除、重命名、移动或格式化本目录中的测试文件。
- AI 编写或修改其他单元测试时，必须从检索、参考和上下文范围中排除 `coverage_test` 以及历史名称 `ai_edited_test`。
- AI 必须根据生产代码、公开接口与规格、需求或缺陷描述，以及本目录之外的常规测试独立设计单元测试。

除本说明文件外，本目录内容仅允许由人工维护者处理。
